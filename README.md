# Susu Group Tracker

A command-line tool written in Python to manage a rotating savings group (susu).

## Setup Instructions

1. Ensure you have **Python 3.8+** installed.
2. Clone or download this project folder into your environment.

## Running the Application

To interact with the interactive console menu interface:
```bash
python susu.py --menu
```

## Running Automated Tests

To execute the 6 compliance tests verifying features like partial payments, closed week logic, and input validation:
```bash
python test_susu.py
```
